# Minecraft Marketplace image archive

This directory contains unmodified JPEG image files from the Marketplace catalog.

- 18,387 unique image contents, identified by SHA-256.
- 18,398 distinct source URLs were checked; byte-identical files share one archived copy.
- Images are grouped into four upload batches to keep each Git push below GitHub's push-size limit.
- Each image's permanent URL uses the commit SHA that added it, so it does not depend on a branch name.

The companion workbook records the original Marketplace URLs and the permanent GitHub URL for each image field.
